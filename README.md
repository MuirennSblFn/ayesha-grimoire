# Grimoire de la Brume

Exemplaire des Gris du bestiaire d'Ayesha.

- `index.html` : la page du grimoire (ne pas modifier).
- `grimoire.json` : le contenu du grimoire. Pour le mettre à jour, remplacez tout son contenu par le code copié depuis le bouton « Publier pour les joueurs » du Grimoire du Maître.
